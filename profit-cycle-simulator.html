⚠️
Read this before using the simulator — timing changes everything
This strategy works best when set up before or during a price pump, not after one has already happened. If you're reading this after an unexpected rally, the pump you needed to sell into may have already occurred. Using this tool without understanding where you are in the cycle can give misleading results.
Before the pump — ideal
Set your full sell and buy ladder now. Both phases work as designed. This is the highest-upside scenario.
During the pump — still good
Set sell ladders above current price to catch remaining upside. Set buy ladders below for the pullback. Partial strategy, still effective.
After the pump — adjust
The sell phase may have passed. Focus on buy ladders only — accumulate tokens on the pullback. Skip sells or set them far above current price for the next cycle.
At the bottom — accumulate
Ideal entry for the next full cycle. Set buy ladders just below current price to catch the final dip, then set sell ladders for the next pump. Maximum token accumulation potential.
Honest note: No tool can tell you exactly where in the cycle you are right now — that requires your own judgement about the asset's history and current market conditions. HEX historically follows sharp pumps with meaningful pullbacks, but the timing and depth are always uncertain. This simulator shows you the mechanics of the strategy — you still need to make the call on when to deploy it.
How This Works
Simulate a strategy where you sell a portion of your tokens as price rises, bank the proceeds as USD, then buy back more tokens as price falls — ending each cycle with the same or more tokens than you started with, plus profit banked. The key insight: selling 25% at 2× and buying back at 1× leaves you with more tokens than you started with, because the tokens you sold bought more on the way down than they represented on the way up. If the pump has already happened, focus on the buy ladders below current price to accumulate on the pullback — then set sell ladders for the next cycle.
